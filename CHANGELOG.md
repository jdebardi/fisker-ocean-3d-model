# Changelog

## v3.0.0 — first public release

- Standard and lightweight controllable GLBs plus editable Blender source.
- Recolourable body, six wheel presets, yaw, steering and wheel roll.
- Independent headlights/tail lights, additive high beam, brakes, indicators/hazards, reverse and optional soft front spill.
- Four framed opening doors, fixed windscreen/quarter panes, forward rear handles with retracting motion, opening hatch and sliding front roof.
- Shared solar gradient texture and closed-roof UV atlas across both roof sections.
- Bundled local/HTTP interactive viewer and a continuous 30-second MP4, including handle retraction close-up and Great White ending.
- Vendor-neutral AGENTS.md and llms.txt; engine-independent and platform-specific integration guides.
- Explicit CC BY 4.0 asset/documentation and MIT software licence scopes, original-creator attribution and complete licence texts.
- Release metadata 3.0.0; runtime schema remains 2.0. Geometry is based on the completed internal 2.3.3 development asset.

Earlier 2.x packages were internal development deliverables. The first public tag is v3.0.0.
