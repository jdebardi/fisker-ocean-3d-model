## This adaptation

Adapted for the **fisker-ocean-3d-model** project maintained by [jdebardi](https://github.com/jdebardi). The original model has been substantially modified; it is not an unmodified redistribution or manufacturer CAD.

Changes include repaired body/shoulder/rear-glass geometry, squared wheel arches, roof/spoiler smoothing, revised rear badge and OCEAN lettering, restrained recolourable materials, wheel families and hub placement, steering/roll pivots, body-mounted lamp regions and beam geometry, D-pillar and mirror indicators, four articulated doors with complete window sashes, fixed windscreen/quarter panes, forward rear handles with sliding pivots, an opening rear hatch, a lift-and-slide front roof, a shared solar texture/UV atlas, and a simplified cabin with a three-seat rear bench.

The project also adds runtime control references, JSON binding metadata, integration documentation, an interactive viewer and a demonstration video. Release **v3.0.0** is the first intended public GitHub release. Earlier 2.x labels refer to development packages.
